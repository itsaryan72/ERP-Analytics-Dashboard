# ERP Manufacturing & Inventory Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end ERP Analytics solution using PostgreSQL and Power BI.

The dashboard helps analyze:

- Revenue Performance
- Profitability
- Inventory Levels
- Product Performance
- Customer Analysis
- Warehouse Stock

---

## Tools Used

- PostgreSQL
- SQL
- Power BI
- DAX

---

## Database Structure

### Products Table
Contains product master information.

### Sales Table
Contains customer sales transactions.

### Inventory Table
Contains warehouse inventory information.

---

## Key KPIs

- Total Revenue
- Total Profit
- Quantity Sold
- Current Stock
